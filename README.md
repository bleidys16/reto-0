# Blog con Comentarios - Reto 0

Aplicación web en Python (Flask) con base de datos SQLite para publicar entradas de blog y permitir comentarios de usuarios registrados.

## Enunciado
- **Aprendiz:** Bleidys Paola Larios Torregrosa
- **Proyecto:** 5. Blog con comentarios

## Requisitos y Ejecución
1. Crear y activar entorno virtual:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```
2. Instalar dependencias:
   ```bash
   pip install -r requirements.txt
   ```
3. Ejecutar la aplicación:
   ```bash
   python app/main.py
   ```
4. Abrir en el navegador: `http://localhost:5000`
